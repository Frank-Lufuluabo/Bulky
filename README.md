## About The Project

The **Online Bookstore Application** is a fully integrated platform designed to facilitate seamless online book purchases, incorporating both front-end and back-end development.  

Built with **ASP.NET Core MVC**, it features a modern, responsive interface powered by **Bootstrap**, ensuring an intuitive and user-friendly experience.  

For enhanced security and access control, the platform utilizes **Microsoft Identity** to provide robust authentication and user management, catering to both customers and store administrators. Additionally, **Stripe Connect** is integrated to enable secure, efficient, and seamless payment processing, delivering a reliable and frictionless transaction experience.

## Installation

1. Clone the repo
```sh
git clone https://github.com/Frank-Lufuluabo/Bulky.git
```
2. Open the project Directory in your local machine
```
cd Bulky
```
3. Restore .NET Dependencies
```sh
dotnet restore
```
4. Run the Application
```
dotnet run
```
